# @mogura/moguchart

Vue, React, Angular など、どのフレームワークでも動作する、軽量でインタラクティブな Web Components 製ガントチャートコンポーネントです。

## 特徴

- 🚀 **フレームワークに依存しない**: Lit (Web Components) 製のため、あらゆる環境で動作します。
- 🖱️ **インタラクティブ**: ドラッグ＆ドロップによる期間移動と、右端ドラッグによるリサイズに対応。
- 🎨 **カスタマイズ可能**: CSS 変数を使用してスタイルを調整可能（予定）。

## インストール

```bash
pnpm add @mogura/moguchart
# または
npm install @mogura/moguchart
```
